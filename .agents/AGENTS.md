# IWP 통합 관제 및 재고관리 시스템 개발 명세 및 사용 설명서 (AGENTS.md)

이 문서는 **IWP 창고 및 생산/현장 통합 관제 시스템**의 전체 소프트웨어 아키텍처, 핵심 비즈니스 로직 분석 및 상세 사용법 가이드를 담고 있습니다. 

---

## SECTION 1: 시스템 개요 및 기술 스택

본 시스템은 공장의 생산 계획 오더 예약, 현장 작업자들의 실시간 시간 공수 기록 및 정산, 그리고 이카운트 ERP 연동을 통한 재고 통합 모니터링/수요 예측 기능을 하나로 통합한 플랫폼입니다.

*   **Frontend**: Streamlit (Python 기반 데이터 애플리케이션 프레임워크)
*   **Backend / Database**: Supabase (Postgres 호환 클라우드 RDBMS)
*   **RPA Engine**: Selenium Webdriver & Python (이카운트 ERP 자동 크롤링)
*   **Styling**: Premium HSL CSS Custom Theme (`utils/style.py` 기반 다크/글래스모피즘 테마)

## SECTION 2: 핵심 비즈니스 로직 분석

### 2-1. 3단계 사용자 권한 시스템 (main_dashboard.py)
사용자의 역할(Role)에 따라 메뉴 노출 및 접근 권한을 3단계로 완벽히 분리하여 안전하게 통제합니다.

1.  **🏰 최고 관리자 (Admin)**
    *   **인증 방식**: 설정된 최고 관리자 비밀번호 입력 (기본값: `admin123`)
    *   **접근 권한**: 관제실 대시보드 조회 및 수정, 생산 계획(오더) 발행, 작업 현장 카테고리 구성, 실시간 가동 현장 강제 종료 및 취소, 재고 분석 및 임박 KPI 조회, 재고/BOM 엑셀 업로드 및 편집, RPA 강제 수집 트리거 및 비밀번호 일괄 관리.
2.  **👥 일반 실무자 (Staff)**
    *   **인증 방식**: 설정된 실무자 비밀번호 입력 (기본값: `staff123`)
    *   **접근 권한**: 생산 계획 관리, 현장 기록 열람, 재고관리 분석 탭 조회. (민감한 정보인 통합 대시보드 통계 리포트, 카테고리 관리, 재고 환경설정 및 RPA 직접 제어 등은 숨김 처리)
3.  **🚩 현장 작업자 (Guest)**
    *   **인증 방식**: 비밀번호 없이 **[접속]** 버튼 즉시 클릭 (`""` 빈값)
    *   **접근 권한**: 오직 **[현장 기록 (field_input.py)]** 단 하나의 메뉴만 노출. 작업자들은 다른 화면을 볼 수 없으며 본인 공정의 타이머 작동 및 실적 입력에만 집중할 수 있습니다.

### 2-2. 실시간 공정 타이머 및 비례 안분 정산 (pages/field_input.py)
현장용 모바일/태블릿에 적합하게 1초 자동 리로드(`@st.fragment(run_every=1)`) 구조로 설계되어 있습니다.

1.  **공수 (Man-Seconds) 누적**:
    *   타이머 시작 시점(`last_started_at`)과 현재 시각의 시차에 **투입 인원수**를 곱해 실시간 인시 공수(`work_history` JSON 데이터 내)를 계산 및 누적합니다.
2.  **정지 / 재개 및 수동 정보 수정**:
    *   일시 정지 시 그때까지의 공수를 날짜별로 누적합니다. 수동으로 작업 시간, 인원수, 목표 수량을 수정하면 오늘 날짜의 공수를 역산하여 재배분합니다.
3.  **현장별 개별 메모**:
    *   각 작업 현장의 제어 버튼 라인 **[정보수정 | 정지 | 종료 | 메모]**에서 개별적으로 메모를 저장하면, 해당 현장명 옆에 **`📝` 아이콘**이 표시되며, 타이머 아래에 **`💬 메모: [내용]`**이 실시간 노출됩니다.
    *   Expander 타이틀바 옆에는 해당 그룹 내에 작성된 총 메모 개수가 요약 표시됩니다 (`| 📝 메모 N건`).
4.  **비례 안분 정산 및 종료**:
    *   그룹 내의 모든 동급 현장이 최종 종료(정산대기 ➡️ 최종종료)되는 순간, 각 현장별로 투입된 누적 공수(Man-Seconds) 비율에 맞춰 완제품 생산 물량을 비례 배분합니다.
    *   그 후 최종 정산 데이터를 `work_logs` 테이블로 이서트(이관)하고, 각 현장별 메모는 `[현장명1] 메모1 / [현장명2] 메모2` 형태로 자동 통합되어 기록으로 남으며, `active_tasks` 테이블에서 실시간 가동 데이터를 정리합니다.

### 2-3. 재고 관리 및 BOM 연동 (pages/warehouse_mgmt.py)
1.  **본사의 가용 창고 기준 집계**:
    BOM 탭의 부자재 매핑 및 생산 가능량 역산은 비가용(보류/불량) 창고를 제외한 **본사의 가용 창고(`is_available == True` & `division == '본사'`) 재고만을 기준**으로 한정하여 작동합니다.
2.  **유효기간 등급 및 제조일자 예외**:
    *   유통기한 만료 0일 미만 품목은 `"🚨 만료"` 등급으로 자동 판정되어 대시보드 KPI 자산 합산 및 경고 필터에 포함됩니다.
    *   날짜 유형(`date_type`)이 `"제조일자"`로 선언된 품목은 만료 기간 판정을 스킵하고 즉시 `"🟢 정상"`으로 판정하여 오작동을 차단합니다.
3.  **통계적 안전재고 및 ROP (재주문점) 분석**:
    *   `inventory_history` 테이블에 하루치 이상의 변동 데이터만 있어도 추이 분석 그래프(Plotly)가 렌더링됩니다.
    *   조달 리드타임 14일, 신뢰수준 95%(Z-score: 1.65)를 적용하여 통계적 안전재고를 역산하고, ROP 점수 미달 시 대시보드에 **🚨 발주 권장** 알림을 노출합니다. 이 추천 값을 버튼 클릭 한 번으로 품목 마스터에 즉시 반영할 수 있습니다.

### 2-4. RPA 수집 최적화 (ecount_agent.py)
*   **본사 계정**: 품목 마스터, 유효기간 상세 데이터, 재고변동표까지 모든 데이터를 정밀하게 전체 수집합니다.
*   **허브 계정**: 속도 단축 및 리소스 최적화를 위해 품목마스터나 변동표 수집 단계를 전면 생략하고, 오직 **단순 창고별재고현황(`get_inventory_balance`)만 수집**하도록 가 제한되어 작동합니다.
*   **품목명 정제**: 허브 재고 동기화 시, 규격 표시 등에 흔히 사용되는 대괄호 및 내부 텍스트(예: `사과 [5]` ➡️ `사과`)를 정규식으로 자동 제거(정제)하여 저장합니다.

## SECTION 3: 사용자 권한별 상세 사용법 가이드

### 3-1. 최고 관리자 (Admin) 사용 가이드
1.  **로그인**: 비밀번호 입력란에 관리자 비밀번호를 입력하고 접속합니다.
2.  **모니터링**: 대시보드 상단에서 실시간 가동 중인 각 현장의 동작 시간과 정산 대기 상태를 실시간 감시하고, 필요시 **[종료]** 또는 **[취소]** 버튼으로 원격에서 현장을 긴급 제어합니다.
3.  **실적 리포트 추출**: 기간 단위(월간/주간/일간)를 선택하고 LPH(시간당 작업량), CPU(단가) 추이 그래프를 확인한 뒤 **[📥 리포트 다운로드]** 버튼을 눌러 정밀 차트와 집계 수식이 포함된 3시트 엑셀 문서를 획득합니다.
4.  **BOM / 품목 마스터 관리**:
    *   [재고관리 환경설정]에서 품목 마스터 다운로드 후, 안전재고/과잉기준을 엑셀로 수정하여 업로드(리터치)합니다.
    *   BOM 설정 엑셀을 업로드하여 완제품과 부자재 매핑을 덮어쓰기 방식으로 대량 등록하거나, 하단 상세 편집기를 통해 개별 추가/삭제합니다.
5.  **비밀번호 관리**: 사이드바 하단의 **[🔑 PW변경]**을 클릭하고 관리자 비밀번호를 확인한 후, Admin용 또는 Staff용 새 비밀번호를 타겟팅하여 손쉽게 변경합니다.
6.  **RPA 제어**: 사이드바의 ERP 동기화 섹션에서 **[🚀 전체 데이터 수집]**을 눌러 에이전트 PC에 크롤링 명령을 원격 전송합니다.

### 3-2. 일반 실무자 (Staff) 사용 가이드
1.  **로그인**: 일반 실무자용 비밀번호(기본값: `staff123`)를 입력하고 접속합니다.
2.  **생산 계획 관리**: 본부에서 오더를 예약 발행하여 현장으로 전달합니다.
3.  **재고 및 ROP 조회**: 재고관리 화면에 접속하여 현재 창고별 자산 현황과 통계 차트를 조회하고 ROP 경고에 맞춰 원자재 발주를 진행합니다.

### 3-3. 현장 작업자 (Guest) 사용 가이드
1.  **로그인**: 비밀번호를 입력하지 않고 **[접속]** 버튼을 누릅니다.
2.  **생산 계획(오더) 수락**: 본부에서 보낸 작업이 있다면 화면 상단에 수락 대기 알림(🔔)이 나타납니다. **[🚀 수락]** 버튼을 누르고 투입 인원을 확인하여 확정하면 타이머가 자동 기동됩니다.
3.  **신규 작업**: 오더 없이 수동 작업을 진행할 경우 화면 하단의 **[🚀 신규 작업 생성 (+)]**을 눌러 현장명, 인원, 목표수량을 지정해 시작합니다.
4.  **일시정지 및 수정**: 휴식 시 **[정지]**를 누르고 복귀 시 **[재개]**를 누릅니다. 작업 도중 투입 인원이 바뀌면 **[정보수정]**을 열어 수동 조정합니다.
5.  **특이사항 기록**: 현장 이슈가 발생하면 **[메모]** 버튼을 눌러 상황을 기재합니다.
6.  **작업 종료**: 당일 실적이 완료되면 **[종료]**를 누르고 팝업창에서 확인을 선택해 최종 완료합니다.

## SECTION 4: 백그라운드 에이전트 제어 명령어 가이드 (RPA 관리용)

에이전트 구동 PC에서 소스 변경 내용을 업데이트하고 백그라운드로 안전하게 재가동하려면, 해당 PC의 **PowerShell** 콘솔을 열고 아래 통합 명령어를 입력하면 됩니다.

```powershell
# 1. 기존 ecount_agent.py 강제 종료
# 2. 로컬 코드 원상복구 및 develop 최신 버전 Pull
# 3. 무음 VBS 런처를 통해 백그라운드 재실행
wmic process where "commandline like '%ecount_agent.py%'" call terminate; git checkout -- ecount_agent.py; git pull origin develop; wscript agent_launcher.vbs
```
